# Sources de veille

## Connecteurs premium (priorité 1 — données structurées)
- **PitchBook** : deals, valos, cap tables, comparables, fundraising.
- **S&P Global / Capital IQ** : financials, M&A, screening.
- **Moody's** : données de crédit / risque.
- **Lusha** : enrichissement contacts dirigeants (email, tel).
- **Apollo.io** : prospection, signaux d'intent.
- **Explorium / VibeProspecting** : fetch d'entreprises + prospects par filtres.

> Note : ces connecteurs doivent être activés dans Claude Code (MCP) pour que l'agent
> puisse les interroger. Vérifie la liste des connecteurs dans les réglages.
